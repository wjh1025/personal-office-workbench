# 个人办公工作台

单文件 HTML，离线可用。手机电脑都能用，数据自动保存在本地浏览器。

**直接下载 `个人办公工作台.html`，双击用浏览器打开即可，不需要联网、不需要安装任何东西。**

## 功能

| 模块 | 说明 |
|---|---|
| **今日焦点** | 逾期任务和卡住的项目标红列出，每条都能一键处理 |
| **今天待办** | 填任务、选轻重缓急、填截止日期，做完打勾；逾期的标红，未来的按日期排在「即将到来」 |
| **灵感速记** | 随手记想法，打标签，按标签或关键词找 |
| **项目跟进** | 记项目名、现在到哪一步、下一步做什么、卡在哪儿；任务可挂到项目下，项目卡上显示关联待办的进度 |
| **每周复盘** | 这周做完几件事、按优先级分布、精力花在哪些项目上、卡点汇总 |
| **数据说明** | 导出备份、导入恢复、清空示例 |

### 页头月历

页头右侧是当月日历，**日期右侧的彩色小圆点**表示当天的事项：

- 🔴 **红** = 逾期还没做
- 🟠 **橙** = 今天有紧急事项，或今天有安排
- 🔵 **蓝** = 未来某天有安排
- 🟢 **绿** = 当天有已完成

点某一天会跳到「今天待办」并只列那一天的任务。鼠标悬停日历可看颜色图例。

## 几个用起来的要点

- **昨天没做完的会自动挪到今天**，不会消失，并且记录顺延了几次
- **每次修改自动保存**，关掉页面再打开内容还在
- **攒到 20 条会提醒你导出一次**，免得哪天清了浏览器全没了
- **换设备**：用「数据说明 → 导出备份」存成 JSON，在新设备打开本文件再「导入」，可选覆盖或合并

## 数据存在哪

数据保存在**打开它的那个浏览器的本地存储**里，不上传到任何服务器。

所以请注意：
- 换浏览器打开，看到的是空的，不是你原来那份
- 清理浏览器数据会丢
- **建议固定用同一个浏览器打开**，并偶尔导一次备份

## 兼容性

- 单文件 184KB，所有 CSS / JS / 图标内联，**零外部依赖**
- 页头配图以 base64 内嵌，断网也能正常显示
- 响应式：宽屏右侧内容居中，手机端侧栏变底部导航、按钮加大
