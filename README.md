# 个人办公工作台

单文件 HTML，离线可用。手机电脑都能用。

**直接下载 `个人办公工作台.html`，双击用浏览器打开即可，不需要联网、不需要安装任何东西。**

## 功能

| 模块 | 说明 |
|---|---|
| **今日焦点** | 逾期任务和卡住的项目标红列出，每条都能一键处理 |
| **今天待办** | 填任务、选轻重缓急、填截止日期，做完打勾；逾期的标红，未来的按日期排在「即将到来」 |
| **灵感速记** | 随手记想法，打标签，按标签或关键词找 |
| **项目跟进** | 记项目名、现在到哪一步、下一步做什么、卡在哪儿；任务可挂到项目下，项目卡上显示关联待办的进度 |
| **每周复盘** | 这周做完几件事、按优先级分布、精力花在哪些项目上、卡点汇总 |
| **数据说明** | 数据文件管理、导出备份、导入恢复、清空示例 |

### 页头月历

页头右侧是当月日历，**日期右侧的彩色小圆点**表示当天的事项：

- 🔴 **红** = 逾期还没做
- 🟠 **橙** = 今天有紧急事项，或今天有安排
- 🔵 **蓝** = 未来某天有安排
- 🟢 **绿** = 当天有已完成

点某一天会跳到「今天待办」并只列那一天的任务。鼠标悬停日历可看颜色图例。

## 数据存哪（v1.1）

数据保存在**同目录的 `工作台数据.json` 文件**里。

**启用方式**：打开页面 → 「数据说明」→「连接到数据文件」→ 选好位置确认。**只需授权一次**，之后每次改动自动写回该文件，下次打开自动连上。

- 需要 **Edge 或 Chrome**（Firefox / Safari 不支持文件访问接口，会自动降级为浏览器本地存储，功能不受影响）
- 换设备：**把整个文件夹拷过去**即可
- `工作台数据.json` 就是数据本体，备份它就够了

状态查看：左下角显示当前数据文件与上次写入时间。

## 几个用起来的要点

- **昨天没做完的会自动挪到今天**，不会消失，并且记录顺延了几次
- **每次修改自动保存**，关掉页面再打开内容还在
- **攒到 20 条会提醒你导出一次**
- 浏览器本地存储始终作为兜底保留一份，文件不可用时数据不丢

## 兼容性

- 单文件约 190KB，所有 CSS / JS / 图标内联，**零外部依赖**
- 页头配图以 base64 内嵌，断网也能正常显示
- 左侧导航栏宽 258px
- 响应式：宽屏右侧内容居中，手机端侧栏变底部导航、按钮加大
